6. AGENTIC AI, LANGGRAPH & AUTONOMOUS SYSTEMS
--------------------------------------------------------------------------------
- Builds agents primarily with LangGraph; also hands-on with LangChain and
  familiar with similar agentic frameworks (CrewAI, DeepAgents class of
  tools).
- Production experience with systems where the agent acted autonomously:
  choosing tools, planning next steps, retrying failed actions.
- Multi-agent systems are a deliberate cost tradeoff, not a knowledge gap:
  * For user-facing production flows he keeps architectures cost-efficient,
    because multi-agent decision-making loops can cost roughly 10x more.
  * He has experimented with more complex patterns: orchestrator, swarm,
    generator-critic loops.
  * The complex patterns run in internal (non-user-facing) agents — code
    review, processing and merging changes, closing tickets — one-off
    operations where the cost per run matters less.

13. LLM COST ECONOMICS (talking point that comes up in interviews)
--------------------------------------------------------------------------------
- Rule of thumb: LLM budget = average operations per user x cost per
  operation.
- His current product serves price-sensitive users (students, people
  between jobs) at a ~$50/month price point. They tolerate occasional
  imperfect recommendations, so user-facing flows deliberately use cheaper,
  simpler agent architectures.
- Two other viable models: growth-stage startups that subsidize unit costs
  to win users, and products creating large enterprise value
  (Palantir-style) where the value justifies expensive pipelines.
